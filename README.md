- Station 2: Fokus auf Klärung des Testprozesses; Testumgebungsausfall aus dieser Station entfernt; eigene Übergangsseite ergänzt.

- Korrekte Auswahl bei der Grenzwertaufgabe bleibt sichtbar hervorgehoben.
