# Test-Rescue-Game – Gesamtversion v1.6

Gemeinsame Spielversion für Woche 1 und Woche 2.

## Änderungen
- QS-Navigation „Zurück / Weiter“ vollständig entfernt.
- Enter-Steuerung bleibt aktiv.
- Station 1 / Testziele: Enthält die Auswahl mindestens ein falsches Fragment, wird sie nicht akzeptiert und bleibt korrigierbar. Ausschließlich passende Fragmente können übernommen werden; danach wird die Aufgabe gesperrt.
- Station 6 / Ressourcenausfall: Das Anklicken markiert nur die Antwort. Erst „Entscheidung bestätigen“ bzw. Enter wertet die Auswahl aus. Bei einer akzeptierten Entscheidung wird die Aufgabe anschließend gesperrt.
- Der Übergang von Woche 1 zu Woche 2 bleibt Bestandteil derselben Gesamtversion.


## Änderung v1.6
- Station 6 / Ressourcenausfall: Mehrfachauswahl ermöglicht. Die beiden sinnvollen Maßnahmen können gemeinsam gewählt werden. Erst „Entscheidung bestätigen“ bzw. Enter wertet aus; ungeeignete Maßnahmen verhindern die Abgabe.
