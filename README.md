# Release 2.0 – Release in Gefahr (Prototyp v0.1)

Klickbarer Browser-Prototyp eines Escape-Spiels rund um Testen und Testmanagement.

## Enthalten
- Station 1: gesperrter Zugang
- Station 2: Testprozess und Teststatus
- Station 3: Äquivalenzklassen und Grenzwertanalyse
- Station 4: Fehlermeldung und Bildschirmfoto
- Station 5: risikoorientierte Testplanung und Ressourcenausfall
- Platzhalter für die noch offenen Escape-Abschlüsse von Station 3 und 5

## Lokal testen
Einfach `index.html` im Browser öffnen.

## GitHub Pages
1. Neues GitHub-Repository anlegen, z. B. `release-2-escape`.
2. `index.html`, `style.css` und `game.js` in den Stamm des Repositorys hochladen.
3. Repository → Settings → Pages.
4. Unter „Build and deployment“ als Quelle „Deploy from a branch“ wählen.
5. Branch `main` und Ordner `/(root)` auswählen und speichern.
6. Nach der Bereitstellung zeigt GitHub unter Pages den Link zur Website an.

Hinweis: GitHub-Pages-Websites sind öffentlich erreichbar. Keine echten Kunden-, Konto- oder internen Unternehmensdaten in diesem Prototyp verwenden.
